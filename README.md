# TAKA-MEER_page

配電盤上部確認用ロボットを開発する「高見舎」プロジェクトの紹介サイトです。

- 公開URL：https://taka-meer.github.io/TAKA-MEER_page/
- 公開されるファイル：`site/`
- 運用方針：[docs/operations.md](docs/operations.md)
- サイト計画：[docs/site-plan.md](docs/site-plan.md)

## ローカルで確認

```
python -m http.server 8000 -d site     # Windows
python3 -m http.server 8000 -d site    # Ubuntu
```

http://localhost:8000 を開く。
