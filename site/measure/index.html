盤の天面を測る

fk-system / ss-system

昇降機に取り付けた腕で、測定器を配電盤の天面に押し当てます。脚立に登って行う測定を、ロボットが代わりに行うための機能です。

いま開発している機能です

このページに書いたのは、目指している動きです（2026年11月時点）。 測定の動きは仕様と設計を決めている段階で、腕の形も検討を続けています。 盤の位置を見つける画像認識はソフトウェアの実装が進み、ロボットのカメラにつなぐ前の段階です。

見るだけでは、脚立を無くしきれない

カメラを持ち上げれば、盤の上面は床から確かめられます。 しかし話し合いの中で、見るだけでは危険な脚立での作業を無くしきれない、という声をいただきました。

そこで、膜厚と板厚（膜や板の厚さ）の測定を人の代わりに行うため、人が使う測定器をそのまま取り付けて押し当てる機能を開発しています。 測定器は、測る面に垂直に押し当てて使います。まず天面の測定を目指します。

示すのは「押し当てられること」

測定器は高価で購入できないため、形と接触の検知だけを再現したモックアップ（模型）を使います。 測定値は扱わず、押し当て終わると「値を保存しました」と表示するだけです。

2つの使い方

立会試験中の測定自律測定
使う場面走行部で盤の前に着いたとき立会試験以外でも。盤の前にいなくてよい
事前の準備走行部の前日準備を使う要らない。起動のたびに地図を作り直す
測る盤目の前の盤盤の配置図から選ぶ（複数可）
測る点天面の中央の1点天面の四隅と中央の5点
人の操作「測定」ボタンを押す自律動作を許可し、盤を選ぶ

立会試験中の測定の流れ

人が押すのは「測定」ボタンだけです。あとの動きは、途中で人の判断を待たずに進みます。

  1. 「測定」を押す

    走行部が盤の前に止まったあと、画面の「測定」ボタンを押します。

  2. カメラが天面を探す

    昇降機とカメラが自動で動き、天面を映して盤の位置を求めます。終わると元の高さに戻ります。天面が見つからなければ、中止するか、人がカメラを動かすかを選びます。

  3. 測る点を決める

    求めた盤の位置から天面の中央を計算し、画面に表示します。

  4. 横を向いて腕を起こす

    盤に向いたまま腕を起こすと盤に当たるので、90°向きを変えてから起こします。腕を十分に上げたら、向きを盤へ戻します。

  5. 測定器を押し当てる

    腕を伸ばして、測定器を天面へ垂直に押し当てます。接触は先端のスイッチで検知します。

  6. 格納して元に戻す

    腕を上げてから90°向きを変えて格納し、機体の向きと昇降機の高さを測定前に戻します。そのあと、走行部の操作に戻ります。

自律測定の流れ

盤の前まで人が運ばなくても、選んだ盤を順に回って測る、挑戦的な機能です。

  1. 周りの盤の配置図をつくるカメラを上げて周囲を撮り、盤の位置と向きを図にまとめます。起動のたびに作り直します。
  2. 測る盤を選ぶ配置図から選びます。複数のときは、盤の正面に向かって右から順に回ります。
  3. 昇降機を下げて、盤の前へ移動するSLAM（走りながら地図をつくり自分の位置を求める技術）で地図をつくりながら進み、必要なら経路を引き直します。
  4. 同じ立ち位置で5点を測る盤の前で認識し直し、点ごとにその場で向きを変えて測ります。
  5. 全部回ったら結果を出す測れなかった盤は飛ばして理由を残し、あとから一覧で選び直せます。

盤の位置は、吊り金具から求める

配電盤の天板には、吊り上げるための金具（吊り金具）が付いています。 カメラの画像から金具を1個ずつ見つけ、金具の位置と向きから、幾何の計算で盤の位置・向き・大きさを求めます。

金具を見つける AI は、CG でつくった画像（合成データ）で学習させています。 CG の画像で確かめた精度は、金具が4個見える盤で、95.5% が位置の誤差15cm以内でした。 実物の画像での精度は、まだ確かめられていません。

USB カメラの映像から金具をリアルタイムで見つけて表示するデモでは、金具を検出できることを確認しました（2026年11月）。 ただしこのデモでは盤の位置までは求めておらず、精度を示すものではありません。

製品に触れるのは測定器だけ

ここまでの機能と違い、この機能だけは製品に触れます。そのため、次のことを決めて設計しています。

  • 製品に触れてよいのは測定器だけ。腕・機体・昇降機は触れさせない
  • 自律測定でも、動き出すのは人が許可して盤を選んでから。走行部の非常停止は、測定の画面でも押せる
  • 昇降機が下がりきっていないと、走り出さない。走っている間に昇降機が動いたら止まる
  • 腕が出ている間は前後に走らない。向きを変えるときは、腕を十分に上げてから
  • 腕を振る範囲は LiDAR（レーザーで周囲の距離を測るセンサー）で確かめ、塞がっていれば腕を動かさない
  • 通信が切れたり途中で止まったりしたら、ロボットは自分から再開せず、人の判断を待つ

押し当てる力の上限や、測定器以外が当たらないことをどう保証するかは、まだ検討中です。
