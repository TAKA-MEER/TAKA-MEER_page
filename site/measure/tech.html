測定・画像認識の技術詳細

fk-system / ss-system

既存の走行部と昇降機・カメラを組み合わせて測定する fk-system と、盤の位置を画像から求める ss-system の設計をまとめます。内容は2026年11月9日時点の仕様です。

開発の状況

範囲状態
fk-system仕様と詳細設計の段階。実装は未着手
測定機構設計は未定で、構成機器は変わりうる。仕様は機器名に依存しない書き方にしている
ss-system推定・依頼の流れ・ROS 2 のノードを実装済み。自動試験は偽の昇降機とカメラを相手にしたもの
ロボットとの接続待ち。昇降機・カメラ側の接続口と、カメラの内部パラメータの校正が残っている

システムの分担

判断は測定機能が持ち、実行はそれぞれのシステムが受け持ちます。

システム受け持つこと
fk-system測定全体の判断。目的地・経路の再計算・盤の前での旋回の指示、昇降機の操作、測る点の決定、測定機構の操作
ss-system方向の範囲を受け取り、カメラと昇降機を動かして、その範囲の盤の位置を返す
th-system経路の計画・走行制御・停止、動き出す前の周囲の確認
hve-system昇降機とカメラ。天井の距離・上限・下限は昇降機の制御器が命令を拒否して守る

fk-system と ss-system は、走行部と同じノートパソコン（Ubuntu 22.04・GPU なし）で、それぞれ別の Docker コンテナとして動かします。 両者は ROS 2 でつなぎます。 画面は走行部の画面を主とし、走行部の盤前の「測定機能へ」やメインメニューの「自律測定」から移ります。

設計思想（抜粋）

FD-5製品に触れるのは測定器だけ。走行系も、測定器以外の部分も製品に接触させない
FD-6測定機構の構成機器は変わりうる。機器を替えても仕様が変わらないように書く
FD-8人の代わりに操作の判断の一部を行う。判断は fk-system、実行する制御は各システムが持つ
FD-11昇降機は fk-system と ss-system の両方が動かす。ss-system の操作中に動かさないよう気をつけるのは fk-system
FD-12fk-system は走行部に対して人と同等の権限を持つ。明示操作は「許可する」の押下と盤の選択
FD-14走行の前の安全は fk-system が自分で確かめる。ss-system の後片付けを当てにしない
SSD-6ss-system は盤の位置を返すだけの機能とし、測定以外のシステムからも使えるようにする

昇降・カメラと走行部を直接つなぐ設計は持ち込みません（hve-system の HD-1 はそのまま）。走行と昇降を組み合わせる判断は fk-system に置きます。

測定機構の制御

測定機構は昇降機に取り付いて一緒に上下し、測定器を前後に動かせます。左右には動かせないので、クローラーのその場旋回で合わせます。

制御器受け持つこと
アームの制御器腕の根元に置き、無線と電池で動く。腕の伸縮・先端の上下、接触の検知（スイッチ）、天面までの距離（距離計）、腕の角度の検知。測定の間は昇降機を主導して動かす。腕の操作画面を自分で配信する
昇降機の制御器昇降機と、腕を起こすドラム。送られてくる腕の角度が一定になるようにドラムをフィードバック制御するので、誰が昇降機を動かしてもドラムがついていく

1点を測る手順

  1. 90°旋回 → 昇降機を上げる → 腕を起こす盤に向いたまま起こすと腕が盤に当たる。左右は腕が振れる範囲が空いている側を選ぶ。
  2. 腕を十分に上げ、90°戻して向きを合わせる十分とは、腕が盤の天面の排気口と余裕を足した高さより上に出ること。
  3. 開始の指示と測定点までの水平距離をアームの制御器へ渡すここから「伸びを戻す」までをアームの制御器に任せる。
  4. 腕を伸ばし、距離計の値で昇降機を大まかに下げ、先端で当てる測定器はモックアップなので値は扱わず、「値を保存しました」と示す。
  5. 先端を上げ、伸びを戻すこの状態なら、腕を起こしたまま次の点へ旋回してよい。
  6. 腕を十分に上げて 90°旋回し、格納する立会試験では、着いたときの向きと測定前の高さへ戻してから「測定を終えた」を返す。これが走行部の停止命令を解く合図。

最後に押し当てる動きの機構は検討中です。昇降機は自重で下がるので、昇降機を下げて押し当てるとロープがたるみます。いまの仮の構成では、腕の先端の上下で当てます。

安全の決まり

値はいずれも暫定で、実機で調整します。

走行と昇降の排他

場面振る舞い
動き出す前昇降機が下端に着いていなければ、目的地も発進も出さない。要れば先に自分で下げる
走っている間昇降機が下端から 50mm 以上離れたら「停止」（走行の揺れを実機で測って決め直す）
盤の前での旋回測るために昇降機を上げるので、高さで止める対象から外す。腕を起こしたまま並進はしない
盤の前の立ち位置1盤につき1か所。盤面から機体の中心まで 0.389m 以上離す（走行部の動き出す前の確認に盤を入れないため）
一時停止からの再開いつも人の「走行」で行う。fk-system が自分の判断で発進を出さない

測れない・動けないとき

扱い場面
その盤を飛ばす経路が見つからない／天面が見つからない／腕が振れる範囲が左右とも塞がっている／正面側の床が塞がっていて立てない
全体を止めて人を待つ腕が出たまま動けない／昇降機を下げられない／昇降機の高さか腕の状態が読めない／ss-system の後片付けの完了が来ない
腕が出ている間に通信が切れた昇降機も動かさず止める（下げると伸びた腕が盤へ降りるため）。通信が戻っても自分から再開せず、続けるか格納するかを人が選ぶ
自己位置を見失った地図と配置図を信用せず、人が自律測定に入り直す。盤の前で腕が出ているときは、人がジョグと腕のマニュアル操作で格納する

腕が振れる範囲は、fk-system が範囲を渡し、走行部が LiDAR で確かめて左右それぞれ「空いている／塞がっている／確かめられない」を返します。「確かめられない」は塞がっているのと同じに扱います。 LiDAR が見るのは床から約32cmの水平な面だけなので、開いた盤の扉のようにそれより上にある物は当面確かめません。既知のリスクとして残し、試験で様子を見ます。

人の操作は拒否せず、昇降機と腕は最後の操作が勝ちます。操作されたら自動の動きは止まり、人を待ちます。異常のときに人が行うジョグと腕のマニュアル操作は、人が責任を負います。

画像認識（ss-system）

受け取るものと返すもの

受け取る盤を探す方位角の範囲（機体の前が 0°）と制限時間
返す盤ごとの天面の矩形（中心・高さ・向き・幅・奥行き）と確からしさ（位置と向きの標準偏差、使った金具の数）、実際に見た方位角の範囲
見つからないとき空の一覧と理由（金具が見えない、盤に組めない、必要な高さまで上がれない、時間切れなど）
座標依頼を受けた時点の機体を基準にしたローカル座標系。LiDAR の地図は使わない
終わり方「結果」と「後片付けの完了」を分けて返す。依頼側は完了を受けるまで機体と昇降機を動かさない

推定の方法

1280×720 の静止画を、必要なときだけ撮ります。カメラは天板より 0.6〜0.9m 上から見下ろし10°以上、盤まで5m以内を前提に、ヨーを少しずつ振って撮ります。

  1. 検出YOLO11s-pose で金具を1個ずつ検出する。キーポイントは根元・リング中心・リング面の両端の4点。
  2. 持ち上げ根元の画素を天板の高さの水平面に投影し、両端の2点からリング面の向きを求める。
  3. 統合複数の視点で見た同じ金具を1つにまとめる。
  4. 組分けリング面は盤の中心を通るという取り付けの規則を使い、金具を盤ごとに分ける。
  5. 当てはめ金具3〜4個から長方形を当てはめる。金具2個の盤は、背中合わせの盤の正面2個とみなして正面まで決める。

はじめは盤1面を1つとして検出していましたが、実物の接写で盤を1面も検出できず、金具2個しかない背中合わせの盤も解けなかったため、金具を1個ずつ検出する方式に変えました。

カメラの位置には、昇降部が配信する高さと、サーボの目標角を使います。盤の高さはカメラ1台では測れないため既定値を使い、測った値でないことを結果に示します。 推論は CPU で動かし、ノートパソコンで1枚約250msでした。学習はデスクトップPCの GPU で行います。推定には ultralytics（AGPL-3.0）を使っています。

合成データでの結果

Blender で作った合成データの評価用セット（100シーン×4か所）の結果です。実物の画像での定量評価はできていません。

項目結果
金具の検出率／適合率99.5% / 98.2%
根元の誤差（中央値）0.35 px
金具4個の盤：組み立てた割合96.1%
金具4個の盤：位置15cm以内95.5%
金具4個の盤：軸5°以内78.4%
金具2個の盤：組み立てた割合84.1%
金具2個の盤：位置15cm以内97.6%
金具2個の盤：正面の取り違え0%

軸が5°以内に入らなかった盤の多くは、幅と奥行の取り違えです。配置図向けの暫定の目標は、検出95%以上・位置±15cm・向き±5°としています。

USB カメラの映像で金具を表示するデモは本番外の道具で、盤の位置は求めません。モデルは本番のカメラの写りに合わせて学習しているため、このデモの結果は精度の根拠にしていません。

まだ決まっていないこと

  • 押し当てる力の上限と、測定器以外が製品に当たらないことの保証の方法
  • 天面へ押し当てる最後の動きの機構
  • 測る点の位置決めに要る精度と、画像によるフィードバック修正を入れるか
  • 「四隅」を縁からどれだけ内側にとるか、立ち位置の余裕の値
  • カメラのヨーの向きを測る方法（昇降機・カメラ側の改良待ち）
  • 実物の画像での検出と盤の位置の精度
