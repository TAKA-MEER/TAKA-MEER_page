# 参考資料

ページ作成の根拠となる資料置き場。**このフォルダは公開リポジトリに含まれ、誰でも閲覧できる**。

- 公開してよい資料 → このフォルダ直下（必要ならサブフォルダを作る）
- 公開できない資料 → `private/`（Git 管理外、ローカルのみ）

## 置き方の例

```
reference/
  overview.md        プロジェクト概要のメモ
  slides/            発表資料（PDF）
  images/            写真・CAD画像の元データ（サイト用に加工したものは site/assets/img/ へ）
  private/           公開NG資料
```

テキストのメモは Markdown で書くと、サイトに転記しやすい。
